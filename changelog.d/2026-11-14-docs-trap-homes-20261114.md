### docs: traps from the 2026-11-14 board archive homed next to the code (2026-11-14)

- `BACKUP_SCOPE.md` section 1: a missing `offsite.conf` does not fail loudly, whatever the live cron
  header says. The `.` fails, `&&` skips the script, and nothing reaches `ktp-offsite.log`.
- `MAP_DEPLOY.md` section 2: build bundles from current `origin/main`, never `/opt/ktp-infra`, which lags
  and predates the #735 HUD-icon pass.
- `ALERT_COVERAGE.md`: an `ac-upload-abort` hit is not by itself a lost bundle; the client re-offers a
  retryable failure at next login.
- `SERVER_SETUP.md`: `netplan --version` prints no version; use `dpkg-query -W netplan.io`.
- `ktp-voice-taunts.service`, `ktp-own-weapon-kills.service`: without `--website` the script exits 0
  and writes no snapshot.
- `ktp-timezone-drift.py`: the whole-second clock tolerance cannot see the 1 s hlstats skew hazard.
- Telemetry contract and causal-links docs: `producer_sequence` is per event type and resets each
  half; the key carries `server_id` and the event type.
- Docs and comments only.
